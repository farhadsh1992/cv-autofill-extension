AI provider

None of these offer a public "log in with your account" flow for third-party extensions like this one — their consumer chat subscriptions are separate from their developer APIs. An API key (billed per call) is the supported way to connect. Add a key for as many providers as you want below — they're all kept ready to use — then pick which one is active right now.

Kimi and DeepSeek don't support reading uploaded PDF files directly — for CV/cover letter/document PDF uploads, switch to OpenAI, Anthropic, or Gemini first. The two Terminal providers don't support PDF uploads either.

OpenAI API key

Stored only in this browser's local extension storage — never sent anywhere except directly to api.openai.com. Get one at platform.openai.com/api-keys.

Anthropic (Claude) API key

Stored only in this browser's local extension storage — never sent anywhere except directly to api.anthropic.com. Get one at console.anthropic.com/settings/keys.

Kimi (Moonshot) API key

Stored only in this browser's local extension storage — never sent anywhere except directly to api.moonshot.ai. Get one at platform.moonshot.ai/console/api-keys. (If your account is on Moonshot's mainland-China platform instead, its keys are issued for api.moonshot.cn and won't work here.)

Gemini (Google) API key

Stored only in this browser's local extension storage — never sent anywhere except directly to generativelanguage.googleapis.com. Get one at aistudio.google.com/apikey.

DeepSeek API key

Stored only in this browser's local extension storage — never sent anywhere except directly to api.deepseek.com. Get one at platform.deepseek.com/api_keys. Open-weight model, but this API is still billed per token like the others above — only DeepSeek's own consumer chat app (chat.deepseek.com) is free.

Terminal providers

These two don't use an API key at all — they run through the claude/codex CLI already logged into your Mac's Terminal (your Pro/Max or Plus/Pro/Team subscription), via a small native messaging bridge to the companion Mac app's own executable. A browser extension can't run a terminal or install anything itself, so this needs a one-time setup step outside the browser — see below. Chrome and Firefox only; Safari and Orion don't support this kind of bridge.

Claude Code (Terminal)

No API key — uses whatever account is logged into the claude CLI.

Set up (one-time, in Terminal)

1. Install Claude Code, then run claude auth login — see the docs.

2. From this extension's folder, run:

bash native-host/install.sh

It'll ask for this extension's ID (from chrome://extensions with Developer mode on) and register the bridge. Then come back here and click "Check bridge".

OpenAI Codex (Terminal)

No API key — uses whatever account is logged into the codex CLI.

Set up (one-time, in Terminal)

1. Install Codex CLI, then run codex login — see the docs.

2. From this extension's folder, run:

bash native-host/install.sh

Same installer as Claude Code above — one run sets up both. Then come back here and click "Check bridge".

Backup

Export downloads a single JSON file with everything: CV, cover letter, notes, addresses, resources, CV style, and your API keys for all four providers — enough to fully restore this extension after a reinstall or on a new browser via Import. This file contains your API keys in plain text — keep it somewhere private (not a public folder, not a GitHub repo, not shared with anyone) and never commit it anywhere. To "update" a backup, just export again over the same file.
