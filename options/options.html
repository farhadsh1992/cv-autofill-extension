AI provider

None of these offer a public "log in with your account" flow for third-party extensions like this one — their consumer chat subscriptions are separate from their developer APIs. An API key (billed per call) is the supported way to connect. Add a key for as many providers as you want below — they're all kept ready to use — then pick which one is active right now.

Kimi doesn't support reading uploaded PDF files directly — for CV/cover letter/document PDF uploads, switch to OpenAI, Anthropic, or Gemini first.

OpenAI API key

Stored only in this browser's local extension storage — never sent anywhere except directly to api.openai.com. Get one at platform.openai.com/api-keys.

Anthropic (Claude) API key

Stored only in this browser's local extension storage — never sent anywhere except directly to api.anthropic.com. Get one at console.anthropic.com/settings/keys.

Kimi (Moonshot) API key

Stored only in this browser's local extension storage — never sent anywhere except directly to api.moonshot.ai. Get one at platform.moonshot.ai/console/api-keys. (If your account is on Moonshot's mainland-China platform instead, its keys are issued for api.moonshot.cn and won't work here.)

Gemini (Google) API key

Stored only in this browser's local extension storage — never sent anywhere except directly to generativelanguage.googleapis.com. Get one at aistudio.google.com/apikey.

Model per action

Use a different provider for specific actions — e.g. a cheap model for autofill, a stronger one for rewriting your CV. Leave any of these as "Active provider" to just follow the selection above.

About me / notes

Labeled notes the AI can draw on — things not in your CV, availability, preferences, whatever's useful. Add as many as you want. Used the same way as your CV when filling forms, writing cover letters, and answering questions in the popup.

Add a note

Or upload a PDF, Word (.docx), or .txt file — a diploma, certificate, reference letter, anything worth the AI having as context. Its text is extracted and saved as a labeled note, same as above.

Addresses

Labeled physical addresses — home, mailing, previous employer, whatever applies. Used to fill address-shaped fields (street, city, postal code, country) during autofill and Ask AI.

Saved addresses

Resources

Add links to your own websites (portfolio, GitHub, personal site) — their text content is fetched once and saved as extra context. You'll be asked to approve access to each site the first time. Notes added from the popup's "Add info" button land here too.

Backup

Export downloads a single JSON file with everything: CV, cover letter, notes, addresses, resources, CV style, and your API keys for all four providers — enough to fully restore this extension after a reinstall or on a new browser via Import. This file contains your API keys in plain text — keep it somewhere private (not a public folder, not a GitHub repo, not shared with anyone) and never commit it anywhere. To "update" a backup, just export again over the same file.

Save job settings

Configures "Save this job" in the popup — extracts job title, company, location, and requirements from the current page with AI.

Applied jobs

Every "Save this job" click in the popup adds a row here, then downloads a fresh Word (.docx) table and a JSON file with everything below — browsers can't silently keep writing to one file on disk, so pick the same file/folder each time you're asked, to keep one running table. This table itself is always live here regardless of what you do with the downloads — edit "Results" or remove a row any time, then re-export to get an updated file.
