Farhad's CV AutoFill — Options

AI provider

Neither OpenAI nor Anthropic offer a public "log in with your account" flow for third-party extensions like this one — the ChatGPT/Claude.ai subscription login is separate from their developer APIs. An API key (billed per call, separate from any Plus/Pro subscription) is the supported way to connect.

OpenAI API key

Stored only in this browser's local extension storage — never sent anywhere except directly to api.openai.com. Get one at platform.openai.com/api-keys.

Anthropic (Claude) API key

Stored only in this browser's local extension storage — never sent anywhere except directly to api.anthropic.com. Get one at console.anthropic.com/settings/keys.

Your CV

Upload a PDF or Word (.docx) file, or paste plain text. Re-uploading replaces the saved CV.

Or paste CV text

Parsed CV data — edit if the AI got something wrong, then Save.

Your cover letter

Upload a past cover letter (PDF or .docx), or paste text. This is used as a style/tone reference when generating a new, tailored cover letter from the popup — it's never sent to a job site, and never copied verbatim.

Saved cover letter text — edit freely, then Save.

About me / notes

Free-form background the AI can draw on — things not in your CV, availability, preferences, whatever's useful. Used the same way as your CV when filling forms, writing cover letters, and answering questions in the popup.

Resources

Add links to your own websites (portfolio, GitHub, personal site) — their text content is fetched once and saved as extra context. You'll be asked to approve access to each site the first time. Notes added from the popup's "Add info" button land here too.

Backup folder (Chrome only)

Optionally mirror your CV, cover letter, notes, and resources to a folder on disk as plain files, purely as your own backup/inspection copy. The extension always keeps working from its normal internal storage in every browser — this is an extra copy, not a replacement.
